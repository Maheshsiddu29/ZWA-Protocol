# ZWA Protocol website

Next.js 15 app for the ZWA Exchange: the public pages (home, markets, verify,
privacy, terms) and the participant UI (sign-in, wallet, portfolio, seller
desk, orders). It is deployed in two different ways:

| Deployment | What works | Backend |
|---|---|---|
| **Public site** (Vercel, `https://zwaprotocol.vercel.app/`) | Home, markets catalog, public Community ZSA Testnet receipts on `/verify`, privacy, terms | None. Every exchange route fails closed. |
| **Local or hosted exchange** | Everything, including demo wallets, quotes, purchases and receipts | `exchange/` services and a pinned Zebra regtest node ([runbook](../docs/phase4e-c-runbook.md), [hosted Compose](../deploy/README.md)) |

The browser never holds keys, signs or broadcasts. The web server reaches the
exchange only through fixed portal actions (`lib/private-orders.ts`), never a
raw node RPC or signer.

## Build

```sh
npm ci
npm run lint     # tsc --noEmit (no ESLint config)
npm run build
./node_modules/.bin/next start -H 127.0.0.1 -p 3210
```

With no environment variables set, this is exactly the public site.

## Environment

No variable is needed for the public site. **Do not set the backend variables
on Vercel**: the portal URL must be a single-label Compose host name
(`http://portal:8790`), so a Vercel deployment cannot reach the engine anyway,
and the session secret and role accounts would only enable logins that cannot
do anything.

| Variable | Used by | Purpose |
|---|---|---|
| `ZWA_PUBLIC_ORIGIN` | hosted | Exact HTTPS origin. Enables `Secure` cookies and strict Origin/Host checks on state-changing routes. |
| `ZWA_SESSION_SECRET` | local, hosted | 64 hex characters; signs session cookies and CSRF tokens. Secret. |
| `ZWA_ROLE_ACCOUNTS` | local, hosted | JSON list of scrypt-hashed operator accounts. Generated by `scripts/provision-local-roles.py`. Secret. |
| `ZWA_DEMO_MODE` | hosted | `1` enables anonymous judge demo sessions with custodial disposable wallets. |
| `ZWA_PORTAL_URL` | hosted | Engine portal on the internal Compose network. |
| `ZWA_PORTAL_TOKEN` | hosted | Bearer token for the portal (32+ characters). Secret. |
| `ZWA_PRIVATE_EXCHANGE_ROOT` | local, hosted | Exchange state root; must match `/private/tmp/zwa4e-*` or `/var/lib/zwa/zwa4e-*`. |
| `ZWA_CHAIN_RPC_PORT` | local | Loopback Zebra RPC port for the read-only portfolio check. |
| `ZWA_PORTFOLIO_BUYER_ID`, `ZWA_PORTFOLIO_SELLER_ID` | local, hosted | The operator accounts allowed to act as buyer and seller. |
| `ZWA_PYTHON` | local | Python interpreter for the local portal subprocess (default `python3`). |
| `ZWA_TRUST_PROXY` | hosted | `1` behind Caddy: rate-limit by the right-most `X-Forwarded-For` entry. |
| `ZWA_STANDALONE` | container build | `1` emits Next.js standalone output (set in `deploy/web/Dockerfile`). |
| `PYTH_API_KEY`, `PYTH_XAU_USD_FEED_ID_VERIFIED` | optional | Indicative gold reference price. Shown only when the full feed ID was checked against official metadata. Secret key. |

There are no `NEXT_PUBLIC_*` variables; nothing above is sent to the browser.
